# ⚽ **Penalty Kick Game**

## 주요 기능 및 특징

#### **1. 3분할 멀티모니터 화면 구성**
코드는 전체 화면을 3개의 영역으로 나누어 각기 다른 정보를 표시하도록 설계.
* **골키퍼 화면**: 골키퍼 플레이어의 웹캠 영상과 수비할 영역(그리드)을 표시.
* **메인 화면**: 게임의 주요 상황(선수 슈팅 모션, 결과 연출 등)을 보여줌.
* **공격수 화면**: 2인 플레이 시 공격수 플레이어의 웹캠 영상과 공격 방향을 표시.

---

#### **2. 게임 플레이 흐름**
게임은 메뉴 화면에서 시작하여 다음 순서로 진행.
1.  **모드 선택**: '1인 플레이' 또는 '2인 플레이' 모드를 선택.
2.  **얼굴 캡처**: OV7670 을 통해 플레이어의 얼굴을 촬영. FPGA에서 전송된 얼굴 좌표가 화면 중앙의 지정된 영역 안에 들어오면 자동으로 캡처.
3.  **게임 진행**:
    * 스페이스 바를 누르면 5초 카운트다운이 시작.
    * 골키퍼는 장갑으로 5개의 수비 영역 중 하나를 선택.
    * 1인 플레이 시 공은 무작위 방향으로 날아오며, 2인 플레이 시에는 공격수가 공의 방향을 지정.
    * 수비 성공 또는 실패에 따라 점수가 부여되고, 결과에 맞는 GIF 애니메이션이 재생.
4.  **게임 종료**: 총 5번의 기회가 소진되면 게임이 종료되고 최종 결과가 표시.

---

#### **3. 하드웨어 연동**
이 프로젝트는 PC에 연결된 외부 장치를 적극적으로 활용.
* **웹캠 (OpenCV)**: `cv2.VideoCapture`를 사용해 두 대의 카메라에서 실시간 영상을 받아와 각 플레이어 화면에 보여줌.
* **시리얼 통신 (PySerial)**: COM 포트를 통해 FPGA와 통신하여 플레이어의 입력을 받음.

---

#### **4. 얼굴 합성 기능 (Photofunia 모듈)**
게임의 가장 큰 특징은 **OpenCV**와 **imageio** 라이브러리를 활용한 얼굴 합성 기능.
1.  게임이 종료되면 승리 또는 패배 상황에 맞는 GIF 영상이 선택.
2.  `Photofunia.py`의 `preprocess_gif` 함수가 GIF의 모든 프레임을 분석하여 얼굴 위치를 탐지.
3.  게임 시작 전에 캡처했던 플레이어의 얼굴 이미지를 탐지된 위치와 크기에 맞게 리사이즈하여 원본 프레임 위에 합성.
4.  이 과정을 거쳐 만들어진 새로운 GIF 프레임들이 최종 결과 화면에 재생
